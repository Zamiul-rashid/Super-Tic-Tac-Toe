## Historical records

The `history/` directory preserves dated specifications, plans, handovers, and
diagnostic evidence. These files explain why the current implementation exists,
but they are not operational runbooks:

- `original-request.md`
- `training-readiness.md`
- `implementation-plan.md`
- `engineering-handover.md`
- `ai-training-blueprint.md`
- `test-readiness-2026-09-10.md`
- `value-head-check.txt`

When a historical command conflicts with the root README or `scripts/README.md`,
the current launcher documentation wins.
